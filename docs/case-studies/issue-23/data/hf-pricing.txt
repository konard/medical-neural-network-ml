== HF Jobs ==
Eligibility [J]: "Jobs are available to any user or organization with a positive credit balance."
  PRO/Team/Enterprise monthly credits count toward that balance. (Earlier PRO/Team/Enterprise-only gate no longer stated.)
Billing [J]: per minute, only while Starting or Running; default timeout 30 min (--timeout 3h).
CLI [JG]: hf jobs run --flavor <flavor> [--timeout 2h] [-e K=V] [-s SECRET] <image> <cmd...>
          hf jobs uv run ... ; hf jobs wait <id> (exit 0 only if all completed) ; hf jobs hardware
Python [JG]: huggingface_hub.run_job(image=, command=, flavor=, timeout=, env=, secrets=, namespace=); wait_for_job(); fetch_job_logs()
SSH into job [JG]: run_job(..., ssh=True); hf jobs ssh <job_id>
